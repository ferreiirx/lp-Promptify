# **App Name**: Promptify Landing

## Core Features:

- Landing Page: Design a modern, responsive, and visually appealing landing page.
- AI Prompt Showcase: Showcase pre-built prompts with a user-friendly interface, enabling users to quickly understand the breadth of the AI tool.
- Content Generation: Tool which helps users generate various content types using AI, with models ready for immediate use, including video scripts, posts, and viral content outlines.
- 3D Mockup Display: Incorporate 3D mockups of the app in use, providing a visual representation of its functionality and interface, and improve understanding.
- Testimonial Section: Implement a section to display user testimonials with high ratings, providing social proof and credibility for the service.
- FAQ Accordion: Design an accordion-style FAQ section to address common questions about Promptify.

## Style Guidelines:

- Primary color: Golden Yellow (#F4A300) to convey a sense of digital luxury.
- Background color: Linear gradient from Black (#000000) to Dark Gray (#1A1A1A), evoking a high-tech atmosphere.
- Accent color: Intense Orange (#FF6A00) for interactive elements and highlights.
- Font: 'Poppins' for a modern, readable UI. 
- Glowy 3D icons to align with the futuristic style.
- Smooth transitions and hover effects with a golden light effect for user interaction.
- Column-based layout with strong visual sections to guide the user and emphasize conversion.
